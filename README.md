Brza Dostava – Manual Testing Project

Project Description

Brza Dostava is a desktop food delivery application created as a practical project during a manual QA training course.

The QA team came up with the application idea, defined its functionality, and prepared the initial documentation and Test Plan before the application was developed.

After the application was completed, each team member tested their assigned part of the application.
